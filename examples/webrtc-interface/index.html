webrtc-interface peer-to-peer DDA over RTCDataChannel

⚠ Requires WebRTC signalling to connect two peers

Once an RTCDataChannel is open, wrap it with createDataChannelInterface() and get full bidirectional DDA RPC with automatic JSON serialisation. Use waitForOpen() to safely await a connecting channel before handing it off.

Peer A (HOST)   createDataChannelInterface({ channel, type: HOST, root: hostApi })  ⟵ RTCDataChannel ⟶  createDataChannelInterface({ channel, type: GUEST, root: guestApi })   Peer B (GUEST)

Loopback demo (same-page P2P via RTCPeerConnection)

Creates two peer connections in the same tab (no signalling server needed). The HOST exposes a calculator API; the GUEST calls it.

Real usage code

import { createDataChannelInterface, waitForOpen }
  from '@actualwave/webrtc-interface';
import { InterfaceType }
  from '@actualwave/deferred-data-access/interface';

// After RTCPeerConnection signalling…
const open = await waitForOpen(channel, 5_000);

const { root: peerApi, stop } =
  await createDataChannelInterface({
    channel: open,
    type: InterfaceType.HOST,  // or GUEST
    root: localApi,
    handshakeTimeout: 5_000,
  });

// Call the remote peer
const result = await peerApi.compute(42);

// Auto-stop on channel close
channel.addEventListener('close', stop);

waitForOpen() states

// readyState: 'open'       → resolves immediately
// readyState: 'connecting' → resolves when 'open' event fires (optional timeout)
// readyState: 'closing'    → rejects immediately
// readyState: 'closed'     → rejects immediately

const ch = await waitForOpen(dataChannel, 5_000); // 5 s timeout
const { root } = await createDataChannelInterface({ channel: ch, type, root: myApi });
