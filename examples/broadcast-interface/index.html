broadcast-interface multi-tab shared state

This tab owns a counter and broadcasts mutations via BroadcastChannel. Open the same URL in another tab — both tabs stay in sync in real time. The createBroadcastInterface wrapper wires DDA's bidirectional RPC protocol on top of the native BroadcastChannel API.

How it works

// HOST tab: exposes the API
const { stop } = await createBroadcastInterface({
  channelName: 'demo:counter',
  type: InterfaceType.HOST,
  root: { increment, decrement, reset, value },
});

// GUEST tab: calls the API
const { root, stop } = await createBroadcastInterface({
  channelName: 'demo:counter',
  type: InterfaceType.GUEST,
});
await root.increment();
const n = await root.value();
