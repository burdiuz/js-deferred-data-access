Deferred Data Access — Examples

Interactive browser demos and code examples for every package in the DDA monorepo.

Core

deferred-data-access

Wrap any object in a Proxy that converts every access into a typed command delivered to an async handler.

coreproxycommands

query-builder

Convert proxy access chains into serialisable QueryDescriptors — ideal for remote procedure calls and batching.

querybatching

Security

proxy-guard

Permission and policy layer — intercepts every command and evaluates it against a configurable rule set.

rbacpolicyauth

Data & HTTP

rest-object

Build REST API calls by traversing a proxy — api.users[42].read() becomes GET /users/42.

httprestfetch

idb-proxy

Fluent proxy API over IndexedDB — db.todos.get(1) without writing a single IDB transaction.

indexeddbstorage

Cross-Context Communication

worker-interface

Main thread ↔ Web Worker. Offload CPU-heavy tasks and call them like local async functions.

workerpostMessage

websocket-interface

Client ↔ server over WebSocket. Bidirectional RPC with automatic serialisation.

websocketrpc

broadcast-interface

Share a live API between browser tabs via BroadcastChannel — no server needed.

broadcasttabs

iframe-interface

Bidirectional parent ↔ iframe communication with postMessage under the hood.

iframepostMessage

mfe-interface

Shell ↔ microfrontend communication via CustomEvents on a shared DOM element.

microfrontendevents

serviceworker-interface

Page ↔ service worker bidirectional RPC with per-client session management.

service-workerpwa

webrtc-interface

Peer-to-peer DDA over an RTCDataChannel. Call remote APIs directly across a P2P connection.

webrtcp2p

webview-interface

Bidirectional DDA RPC between React Native and a WebView over the asymmetric injectJavaScript / postMessage transport.

react-nativewebview
