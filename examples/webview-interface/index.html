webview-interface React Native ↔ WebView bidirectional DDA

⚠ Requires a React Native host — runs in a WebView

The transport between React Native and its WebView is asymmetric: RN injects JavaScript to send, while the WebView calls window.ReactNativeWebView.postMessage() to reply. webview-interface hides this asymmetry behind DDA's standard bidirectional RPC model.

React Native (HOST) ─ injectJavaScript() ──▶ WebView / Browser (GUEST)
React Native (HOST) ◀── ReactNativeWebView.postMessage() ─ WebView / Browser (GUEST)
Both sides get a DDA root proxy — call each other like ordinary async functions.

React Native side (HOST)

import { useRef, useCallback, useEffect } from 'react';
import WebView from 'react-native-webview';
import { initializeHost }
  from '@actualwave/webview-interface';

export default function EditorScreen() {
  const webViewRef = useRef(null);
  const onMessageRef = useRef(null);

  // Stable handler — ref keeps it out of React diffing
  const handleMessage = useCallback(
    e => onMessageRef.current?.(e), []
  );

  useEffect(() => {
    if (!webViewRef.current) return;

    const { onMessage, connection } = initializeHost({
      webView: webViewRef.current,
      root: {
        getConfig: () => ({ theme: 'dark', fontSize: 14 }),
        saveFile: content => persist(content),
      },
    });

    onMessageRef.current = onMessage;

    connection.then(({ root: webApi, stop }) => {
      webApi.setContent('console.log("hello")');
      return () => { onMessageRef.current = null; stop(); };
    });
  }, []);

  return (
    <WebView ref={webViewRef}
             source={{ uri: 'https://…/editor' }}
             onMessage={handleMessage} />
  );
}

WebView side (GUEST)

import { initializeGuest }
  from '@actualwave/webview-interface';

// Runs inside the WebView page (browser context).
// window.ReactNativeWebView must be present.

const { root: nativeApi, stop } =
  await initializeGuest({
    root: {
      setContent(code) {
        editor.setValue(code);
      },
      getContent() {
        return editor.getValue();
      },
    },
  });

// Call React Native methods
const config = await nativeApi.getConfig();
editor.setTheme(config.theme);

// React Native pushes updates too
nativeApi.saveFile(editor.getValue());

Transport details

// HOST → GUEST (React Native → WebView)
// DDA message is JSON-stringified twice to produce a safe JS string literal:
webView.injectJavaScript(
  `window.dispatchEvent(new MessageEvent('message',{data:${JSON.stringify(JSON.stringify(msg))}}));true;`
);

// GUEST → HOST (WebView → React Native)
window.ReactNativeWebView.postMessage(JSON.stringify(msg));
// Received in React Native via <WebView onMessage={e => handle(e.nativeEvent.data)} />
