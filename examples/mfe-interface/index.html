mfe-interface shell ↔ microfrontend

Both sides communicate via CustomEvents dispatched on a shared DOM element. The shell (host) and the MFE (guest) each register distinct event names so messages don't echo back to the sender.

How it works

// The MFE root element is the shared message bus
const element = document.getElementById('mfe-checkout');

// Shell side (HOST) — sends on HOST event, listens on GUEST event
const { root: mfeApi } = await connectMFEInterface({
  element, root: shellApi,
});

// MFE side (GUEST) — sends on GUEST event, listens on HOST event
const { root: shellApi } = await initializeMFEInterface({
  element, root: mfeApi,
});

// Bidirectional: both sides can call each other
const user = await shellApi.auth.user();
await mfeApi.refreshCart();
